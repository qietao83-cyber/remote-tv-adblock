# 画质参数调整指引

## 前提：adb 能做什么、不能做什么

| 项 | adb 可达性 | 原因 |
|---|---|---|
| **屏幕亮度** | ✅ **可读写** | 存在 Android `settings` 的 `screen_brightness`（0-255） |
| 对比度 / 色温 / 锐度 / 饱和度 / 降噪 / 背光 / 图像模式 | ❌ **不可达** | 由芯片 tvserver 的 PQ 模块管理，不在 Android 层 |

**实测依据**：
```bash
adb shell "dumpsys tvservice"          # 只输出音频参数，无画质
adb shell "settings list system | grep -iE 'bright|contrast|color'"
#  → 只有 screen_brightness 一个键
adb shell "ls /data/data/com.xiaomi.mitv.settings"   # Permission denied（需 root）
```

> ⚠️ 不要尝试 `service call tvservice` 直接调 PQ 接口——方法签名未知，可能导致显示异常。

**所以画质参数必须让用户在电视上手动调。** 下面是给用户的建议值。

---

## 亮度（唯一可远程调的）

```bash
adb shell settings get system screen_brightness        # 读
adb shell settings put system screen_brightness 150    # 写（0-255）
```

| 场景 | 建议值（0-255） |
|---|---|
| 晚上关灯 | 90-110 |
| 白天开灯 | 150-180 |
| 省电/护眼 | 80-100 |

---

## 抄作业数值表（给用户手动设）

> 路径：**设置 → 图像与声音 → 图像** → 选「**自定义**」模式（这样才会出现逐项可调）

| 项目 | 建议值 | 原理 |
|---|---|---|
| **图像模式** | 自定义（基底选「标准」） | 「鲜艳」是卖场演示模式：色温 9000K+、饱和度灌满 |
| **背光** | **50** 晚上 / **75** 白天 | 面板发光强度，唯一该随环境变的 |
| **亮度** | **50** | 黑电平（注意：与背光是两个东西） |
| **对比度** | **85** | 白电平。拉到 100 会削掉高光细节 |
| **饱和度** | **50** | 中点。调高 → 肤色发橙 |
| **色调** | **50** | 中点 |
| **清晰度/锐度** | **30**（低） | 电视的锐度 = 给边缘加白边，不是真清晰 |
| **色温** | **标准**（或「暖」） | ★ 最关键。默认普遍偏冷（9000K+，发蓝） |
| **动态对比度** | **关** | ★ 会不断改亮度，暗部细节丢失、亮暗切换闪烁 |
| **动态背光** | **关** | 同上 |
| **降噪** | **关** | 开了有涂抹感，细节丢失 |
| **运动补偿/MEMC** | **关**（电影）/ **低**（体育） | 电影开了变"肥皂剧感" |

### 色温自定义 RGB（若有白平衡调节）

| 通道 | 值 |
|---|---|
| 红 | **+3** |
| 绿 | **0** |
| 蓝 | **−3** |

这是 D65（6500K 影视标准）方向：**降蓝提红**，把默认冷色调拉回中性。

---

## 改完自测（3 项，5 分钟）

| 放什么画面 | 观察 | 调整 |
|---|---|---|
| 白底（网页/文档/雪景） | 白色发蓝？ | 蓝色再减 2 |
| 夜景/暗场景 | 黑成一团？ | 亮度（黑电平）+2~3 |
| 夜景/暗场景 | 黑色发灰像蒙雾？ | 亮度（黑电平）−2~3 |
| 白云/雪地/白衬衫 | 一片死白没层次？ | 对比度 −5 |

---

## 必须提前告知用户的预期

**改成标准/暖色温后会觉得"偏黄"，这是对的。**

眼睛已适应默认的冷色调（偏蓝）。**不要在第一天就推翻它**，1-2 天后适应，再看回冷色反而觉得刺眼发青。

---

## 一句话总结（最省事的改法）

只改这两项就能立竿见影：

1. **色温 → 标准 / 暖**
2. **图像模式 → 电影 / 标准**（别用鲜艳）

---

## 其他显示相关设置（可 adb 调）

```bash
adb shell settings get system screen_off_timeout     # 熄屏超时（毫秒），2147483647 = 永不熄屏
adb shell settings get system screen_saver_timeout   # 屏保超时
adb shell settings get system screen_brightness_mode # 0=手动 1=自动
```

改之前**记录原值**，便于回滚。
